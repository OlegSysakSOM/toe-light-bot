# Публічний Telegram-бот графіків Тернопільобленерго

Це багатокористувацька версія: кожна людина відкриває бота в особистому чаті, надсилає `/start`, вводить населений пункт, вулицю й номер будинку. Бот шукає адресу в довіднику `poweron.toe.com.ua`, визначає чергу `chergGpv` і зберігає окрему підписку. Кожен користувач отримує тільки власний графік.

## Можливості

- `/start` — нова підписка або відновлення раніше вимкненої.
- `/address` — змінити адресу.
- `/status` — перевірити адресу, чергу та стан підписки.
- `/stop` — вимкнути сповіщення.
- `/cancel` — скасувати введення адреси.
- `/help` — список команд.
- Окремий стан і `message_id` для кожного приватного чату.
- Один запит графіка для всіх підписок з однаковою адресою/чергою в межах циклу.
- Публічний довідник адрес кешується через GitHub Actions Cache: перше завантаження сканує сторінки TOE, наступні користувачі знаходяться локально без повторного сканування всього довідника.
- Нове фото при зміні графіка; редагування попереднього фото, якщо змін немає.
- Зашифрована база підписок, Telegram update offset і кеш знайдених вулиць зберігаються у `state.enc`.

## Важливо про затримку команд

У безкоштовному варіанті GitHub Actions запускає цикл орієнтовно кожні 15 хвилин. Тому `/start`, введення адреси та інші команди можуть оброблятися із затримкою до наступного запуску. Telegram зберігає необроблені updates не довше 24 годин; якщо GitHub не запускається понад добу, частина команд може втратитися.

Це не постійний процес 24/7: це короткий cloud-run кожні 15 хвилин. Точний час старту не гарантується GitHub.

## Локальний запуск/перевірка

1. Встановіть Python 3.12+.
2. `python -m pip install -r requirements.txt`
3. Створіть `.env` на основі `.env.example`, додайте `TELEGRAM_BOT_TOKEN` і `STATE_ENCRYPTION_KEY`.
4. `python bot.py --once`

Не запускайте локальний процес одночасно з GitHub Actions для того самого токена: обидва процеси використовують `getUpdates` і можуть конфліктувати.

## Дані та приватність

Усі персональні підписки зберігаються у зашифрованому `state.enc` за допомогою Fernet. У репозиторій не потрапляє відкритий `.env`, токен або відкрита база адрес користувачів. Сам код у Public-репозиторії відкритий. Не втрачайте `STATE_ENCRYPTION_KEY`: без нього зчитати `state.enc` неможливо.

Бот приймає команди тільки в особистих чатах, щоб не розкривати адресу одного користувача іншим учасникам групи. Адреса й черга потрібні для запиту графіка; користувач може вимкнути підписку командою `/stop`.

## Обмеження

- Підтримуються адреси, які присутні в довіднику Тернопільобленерго та мають чергу ГПВ.
- Адресний кеш має ключ `toe-address-index-v1-Linux`. Якщо довідник застарів або сайт змінив адресу/вулиці, видаліть цей кеш у Settings → Actions → Caches; наступний запуск завантажить довідник заново. Також можна змінити `v1` на `v2` у ключі cache в `.github/workflows/check-schedule.yml` і відправити commit.
- API сайту може змінитися, бути недоступним або блокувати автоматичні запити.
- GitHub Actions має обмеження планувальника, а workflow у публічному репозиторії може автоматично вимкнутися після 60 днів без активності репозиторію.
- При збоях сайт/Telegram не трактуються як «змін немає»: останній коректний графік зберігається, після трьох невдалих перевірок користувач отримує попередження.
- Ресурси безкоштовного GitHub-хостингу та швидкість API обмежені; це не обіцянка необмеженої кількості підписок.
