# TOE Public Bot 2.1.0

## Виправлення

- Telegram updates більше не очищаються під час першого запуску після міграції.
- Workflow перевіряє вхідні повідомлення та натискання кнопок приблизно кожні 5 хвилин.
- Оновлення графіків виконуються окремо з інтервалом 15 хвилин, щоб не збільшувати кількість звернень до API TOE.
- Стан підписки не шифрується/комітиться повторно, якщо дані не змінилися; це запобігає створенню коміту кожні 5 хвилин.
- Додано постійну ReplyKeyboard-панель із кнопками додавання/зміни адреси, статусу, вимкнення/відновлення сповіщень і допомоги.
- Додано inline-кнопки вибору адреси, якщо знайдено кілька збігів.
- Callback queries обробляються разом зі звичайними повідомленнями.
- Нове підключення адреси або відновлення підписки примусово запускає перевірку графіка в тому самому циклі.
- Відновлено відсутні поля стану для безпечного оновлення попередньої версії.
- Збережено редагування поточного фото, якщо графік не змінився, і відправлення нового фото, якщо змінився.

## Примітки

- Одна активна адреса на один приватний Telegram-чат.
- Команди `/start`, `/address`, `/status`, `/stop`, `/resume`, `/cancel`, `/help` залишені як резервний спосіб керування; основний інтерфейс — кнопки.
- Через безкоштовне планування GitHub реакція на кнопку може затриматися до наступного запуску (орієнтовно 5 хвилин); точний час не гарантується.

- `/start` лише показує привітання та постійну клавіатуру; додавання адреси починається після натискання кнопки «➕ Додати адресу».
