# Розгортання

Для міграції з попередньої однокористувацької версії виконайте `DEPLOY_MIGRATION.md`.

Потрібні GitHub Secrets: `TELEGRAM_BOT_TOKEN` і `STATE_ENCRYPTION_KEY` (той самий ключ, яким уже було зашифровано старий state.enc). Публічні адреси більше не задаються в налаштуваннях репозиторію: кожен користувач вводить свою адресу в Telegram.
