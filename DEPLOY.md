# Розгортання

Для безкоштовного періодичного запуску використовуйте GitHub Actions. Покрокова інструкція: [DEPLOY_GITHUB_ACTIONS.md](DEPLOY_GITHUB_ACTIONS.md).

Цей варіант не тримає процес постійно запущеним: GitHub приблизно кожні 15 хвилин запускає коротке завдання. Час фактичного старту не гарантується.
